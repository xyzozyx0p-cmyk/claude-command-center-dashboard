# TODO — Claude Command Center

## Защищённый вход и серверный прокси

- Вход выполняется через Manus OAuth и сохраняет совместимую application session.
- Control Plane URL и token хранятся только в server environment; браузер и GitHub их не видят.
- Серверный proxy проверяет авторизованного пользователя перед каждым control-plane запросом и возвращает понятные ошибки.

## Операционный обзор

- Панель показывает состояние основной Instabox-машины, Render watchdog и Cloudflare watchdog с доступным/недоступным/непроверенным статусом.
- Панель показывает состояние control plane, текущую Claude-сессию и выбранную модель.
- Обновление состояния выполняется автоматически, но не блокирует навигацию.

## Задания и Claude

- Пользователь может запустить Claude persistent-сессию, отправить сообщение или задание и увидеть принятие запроса.
- История текущей рабочей панели отображает время, направление сообщения и состояние выполнения.
- Live-вывод Claude обновляется автоматически и доступен для копирования.
- Запуск/перезапуск сессии показывает pending и ошибку, если control plane недоступен.

## Терминал

- Разовая команда отправляется в persistent-сессию и показывает live output.
- Интерактивный терминал использует WebSocket bridge с серверной авторизацией и поддерживает ввод/вывод в реальном времени.
- На мобильном экране терминал остаётся пригодным для ввода и горизонтальной прокрутки.

## Модели и файлы

- Пользователь видит список моделей, текущую модель и может выбрать модель через server proxy.
- Файловый менеджер показывает файлы проекта, поддерживает загрузку и скачивание через server proxy.
- Ошибки доступа к файлу отображаются без раскрытия серверных секретов.

## Адаптивная рабочая панель

- Desktop layout использует navigation rail и три рабочие зоны: overview, задания/вывод и terminal/files.
- Mobile layout перестраивается в вертикальный поток с доступными sticky action controls.
- Интерфейс использует выбранную тёмную янтарную визуальную систему и состояния success/warning/error.

## Проверки и delivery

- `pnpm check` проходит без ошибок.
- `pnpm build` создаёт production frontend/server bundle.
- `/api/health` и `/manus-routes.json` отвечают корректно.
- Preview показывает рабочую панель; публикация выполняется только после явного решения пользователя.
